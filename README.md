# Magic Conch Shell

Magic Conch Shell (Fabric) is a lightweight Minecraft mod that adds a playful oracle you can ask for guidance. Right‑click to get short, randomized answers that turn decisions into spontaneous fun without affecting balance or progression.

## Features
- Ask the conch and receive a randomized response suitable for roleplay, challenges, or settling quick debates.
- Fabric‑first design for quick startup, broad compatibility, and minimal overhead in modern modpacks.
- Ideal for multiplayer moments on community servers, stream events, and party‑style lobbies.

## Usage
- Hold or interact with the Magic Conch Shell and right‑click to receive a randomly selected answer.
