# Security Policy

## Supported Versions

The following versions of Magic Conch Shell currently receive security updates.

| Version | Support status |
| --- | --- |
| Latest release | :white_check_mark: Supported |
| Older releases | :x: Not supported |

## Reporting a Vulnerability

If you discover a security issue or a serious exploit related to this project, please report it privately through GitHub's private vulnerability reporting feature instead of opening a public issue, pull request, or discussion.

To submit a report:

1. Open the repository on GitHub
2. Go to the Security tab
3. Click Report a vulnerability
4. Fill out the report with as much detail as possible

Please include:

- A short description of the issue
- The affected version
- Your Minecraft version
- Your Fabric Loader version
- Steps to reproduce the issue
- Crash logs, screenshots, or proof of concept details if available

If you cannot use GitHub's private vulnerability reporting feature for any reason, you may contact [contact@travikskoot.de](mailto:contact@travikskoot.de) instead.

Reports will usually be acknowledged within 7 days. If the issue is confirmed, a fix will be prepared as soon as reasonably possible. Public disclosure should wait until a fix is available.
