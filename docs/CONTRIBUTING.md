# Contributing

Thanks for your interest in contributing to Magic Conch Shell.

This project welcomes bug reports, ideas, documentation improvements, code contributions, and general feedback. The goal is to keep the project friendly, understandable, and easy to maintain.

## Before you start

Please make sure you:

- Read the Code of Conduct before participating.
- Check existing issues and pull requests before opening a new one.
- Keep changes focused and easy to review.
- Use clear and respectful communication.

## Reporting bugs

When reporting a bug, please include:

- A short and clear title.
- What happened.
- What you expected to happen.
- Steps to reproduce the issue.
- Your Minecraft version.
- Your Fabric Loader version.
- Your Fabric API version, if applicable.
- The mod version you are using.
- Crash logs or screenshots, if available.

## Suggesting features

Feature requests are welcome.

Please include:

- The problem you want to solve.
- Your proposed idea.
- Why this change would be useful.
- Possible alternatives, if you have any.

## Development guidelines

If you want to contribute code:

- Fork the repository and create a separate branch for your change.
- Keep commits small and meaningful.
- Follow the existing project structure and naming style.
- Avoid unrelated refactoring in the same pull request.
- Test your changes before submitting them.
- Update documentation when behavior changes.

## Pull requests

Before opening a pull request, please check that:

- The change solves one clear problem.
- The code is readable and consistent.
- The project still builds correctly.
- Relevant documentation has been updated.
- The pull request description explains what changed and why.

## Style notes

A few simple expectations help keep the project maintainable:

- Prefer readable solutions over clever ones.
- Keep files and functions focused.
- Write names that clearly describe purpose.
- Keep comments useful and concise.

## Questions

If something is unclear, open an issue and ask before starting larger work.
